# logs/

运行期日志与状态文件的落地目录。**内容已被 `.gitignore` 排除，不会进版本控制。**

| 文件 | 内容 |
|------|------|
| `checkin.log` | 每次签到的结果与退出码 |
| `schedule.log` | 计划任务入口的决策过程（是否回退端口、是否拉起客户端等） |
| `push-guard.json` | 失败提醒去重守卫（当日同一原因只推一次，防刷屏） |
| `phase1.log` | Phase 1 引导过程原始日志 |

> 这些文件里会出现本机安装路径、调试 target 的 UUID、签到结果等内容。
> 上报问题前请先自行检查，勿把整份日志贴到公开 issue。
