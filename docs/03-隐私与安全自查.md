# 03 · 隐私与安全自查清单

> 面向"要把本项目分享出去"的场景。每次改动后按此清单过一遍。
> 原则：**仓库里只放代码和文档，不放任何本机数据。**

---

## 一、凭据（最高优先级）

| # | 检查项 | 要求 |
|---|--------|------|
| 1 | WxPusher SPT | 只从 `--spt-file` 或环境变量 `WXPUSHER_SPT` 读；**源码/文档里不得出现 `SPT_` 开头的真实值** |
| 2 | WxPusher AppToken | 同上，环境变量 `WXPUSHER_APP_TOKEN` 或 `~/.wb-checkin/app_token.txt` |
| 3 | accessToken / refreshToken | 本项目**完全不读取**；若将来需要，同样走运行时注入，绝不落盘 |
| 4 | `X-Device-Token` | 不读取、不伪造 |
| 5 | 文档中的示例 | 一律用占位符（`<你的SPT>`），不留"看起来像真的"的样例值 |

一键自检：

```bash
grep -rnE "SPT_[A-Za-z0-9]{8,}|AT_[A-Za-z0-9]{16,}" . --include="*.md" --include="*.js" --include="*.ps1" --include="*.py"
# 期望：无输出
```

## 二、个人标识

| # | 检查项 | 说明 |
|---|--------|------|
| 6 | 渲染进程 target 的 URL | query 里含 `accountSnapshot`（uid / 昵称 / 版本），**打印前必须 `.split('?')[0]`** |
| 7 | 调试协议 UUID | `browser/<uuid>`、`page/<32位hex>` 属于本机会话标识，报告里替换为 `<redacted-uuid>` |
| 8 | 签到活动数据 | `checkin_dates` / `total_credits` / `week_progress` 等属于个人活动记录，报告里替换为 `<redacted>` |
| 9 | 签到历史 | `签到历史.md` 是真实记录 → **必须 `.gitignore`**，仓库里只放 `签到历史.example.md` |
| 10 | 运行日志 | `logs/` 下全部产物 → **必须 `.gitignore`** |

---

## 三、本机环境指纹

| # | 检查项 | 说明 |
|---|--------|------|
| 11 | 绝对路径 | 源码与文档里不得出现 `C:\Users\<你的用户名>\...`、`D:\你的工作区\...`；用参数、环境变量或自动探测代替 |
| 12 | 本机监听端口清单 | 评估报告里的"已监听端口"属于环境指纹，分享时可省略或模糊化 |
| 13 | 会话类型 / 主机名 | 如远程桌面会话编号、机器名，不要写进文档 |
| 14 | 内网 IP / 域名 | 不得出现 `10.x` / `192.168.x` / 公司内部域名 |

---

## 四、`.gitignore` 必备项

```gitignore
签到历史.md
docs/phase1-report.md
logs/*.log
logs/*.json
tests/_sandbox/
tests/result.txt
spt.txt
*.spt
.wb-checkin/
secrets/
```

**验证方法**（不要靠肉眼看规则，用 git 实际判定）：

```bash
# 在项目副本里初始化临时仓库，看真正会被跟踪的文件
git init -q . && git add -A && git ls-files
git status --porcelain --ignored | grep '^!!'
```

期望：`git ls-files` 里**没有**任何日志、历史、报告实例、凭据文件。
